# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be kind and assume good intent. Critique code and ideas, not people.
- No harassment, discrimination or personal attacks, in any form or language.
- Help newcomers. Many contributors here are students.

Report unacceptable behaviour by opening a private security advisory on this repository. Maintainers will review every report and act on it.
